MyKIDS brings a child's day into one place: school, activities, tasks to finish, and rewards to save for. Parents can plan the week and review results, while grandparents and other relatives can join the family conversation.

There is room for play, too. Ray — Лучик in the app — is a little robot with space stories, puzzles, and action missions of his own.

## What you can do

- **Plan the day.** Keep school subjects, activities, recurring family tasks, and reminders in a shared calendar.
- **See how a task went.** Send a comment or photos, review the result, and keep a clear history of the family's decisions.
- **Save for something worth having.** Set up family rewards, earn coins for approved tasks, and choose a savings goal. Parents manage the reward rules and confirm payouts.
- **Stay in touch.** Use family and private chats, voice messages, and audio or video calls.
- **Explore with Ray.** Discover space stories and puzzles, then take on nine action missions with drones, abilities, and upgrades. The action missions work offline and do not spend family coins.
- **Make it feel familiar.** Choose from five visual themes. Saved plans and supported offline changes remain available when the connection drops.

For scheduled tasks, the time to do something and the time to report it can be different. A child can finish a morning task on time and mark it later; an adult still reviews the result.

## Try MyKIDS

The current Android build is **0.1.122**, for **Android 8 and newer**.

[Download the APK](https://api.xn--80ajzgig.online/downloads/MyKIDS-0.1.122.apk)

Joining an existing family requires an invitation from its parent account. To build the Android app, see the [development guide](docs/DEVELOPMENT.md).

This repository contains **the Android application only**. Server code, deployment tools, and server configuration are kept private.

The public sources match version 0.1.122. Development continues, and physical-device testing is still ahead; the current checks use automated tests and Android emulators.
